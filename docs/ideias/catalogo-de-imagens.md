# Catálogo de sistemas para baixar

## O que outros fazem

O Quickemu (`quickget`) e o Quickgui buscam e baixam quase 1000 sistemas
(Windows, macOS, BSDs, centenas de distros) e criam a VM já configurada.

## Encaixe no escopo

**Conflita** com o non-goal "dezenas de distros pré-empacotadas" do
`CLAUDE.md`. Manter um catálogo próprio é manutenção sem fim (URLs,
checksums, versões).

## Variante compatível

Se a necessidade aparecer, integrar o `quickget` como fonte opcional, em
vez de manter um catálogo: a OmaVM mostra "Baixar um sistema…" só quando o
`quickget` está instalado, e o resto do fluxo continua sendo "criar Machine
a partir de uma ISO". Precisa de necessidade real documentada antes (Rules
for AI Agents #7).
